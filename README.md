# XP Bottler Fabric Mod for Minecraft 26.2

Turns vanilla glass bottles and loose XP into vanilla Bottle o' Enchanting items.

## Features

- Crouch-right-click with a vanilla glass bottle to spend 20 raw XP and create one Bottle o' Enchanting.
- Bottle o' Enchanting keeps its normal vanilla use behavior.
- No custom bottles, blocks, hoppers, recipes, or textures.

Using raw XP points keeps the cost predictable and avoids level-scaling weirdness.
